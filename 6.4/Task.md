# Урок 6.4 — Кінцевий автомат: електронний сейф

## Завдання

Уявіть, що ви розробляєте прошивку для електронного сейфа. Для вводу пароля є рівно одна кнопка.
Пароль — послідовність натискань: **Коротке – Коротке – Довге**.

Якщо користувач помилився (натиснув не те) або «затупив» (нічого не натискав більше 3 с) —
система має миттєво скидатися в початковий стан.

Завдання — написати кінцевий автомат (Consumer), який приймає події від ідеального автомата
кнопки (Producer).

### Код
- [ ] Таймаут «затупив» рахується від останньої події, а `LONG` приходить лише через 1 с утримання - автомат скидається, поки користувач тримає кнопку. Потрібна подія «натиснуто» (`PRESS_DOWN`) для перезапуску таймауту.
- [ ] Час у Producer рахується через `==` (`case 50:`, `case 1000:`) при кроці 10 мс - зміна періоду опитування ламає таймінги. Порівнювати через `>=`, а краще через тіки.
- [ ] `hold_time += 10` замість реального часу (`xTaskGetTickCount`, `vTaskDelayUntil`) - «секунда» кнопки залежить від завантаження CPU.
- [ ] Відпускання без антибрязкоту: один «стрибок» контакту під час утримання дає зайве коротке натискання.
- [ ] Магічні числа 10/50/1000/3000 і `#define` замість `constexpr` у `.cpp`.
- [ ] Успішне відкриття логується через `ESP_LOGE`.
