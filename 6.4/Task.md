# Урок 6.4 - Кінцевий автомат: електронний сейф

## Завдання

Уявіть, що ви розробляєте прошивку для електронного сейфа. Для вводу пароля є рівно одна кнопка.
Пароль - послідовність натискань: **Коротке - Коротке - Довге**.

Якщо користувач помилився (натиснув не те) або «затупив» (нічого не натискав більше 3 с) -
система має миттєво скидатися в початковий стан.

Завдання - написати кінцевий автомат (Consumer), який приймає події від ідеального автомата
кнопки (Producer).
