# Еталон 1.3 — Поліцейська мигалка

Приклад того, як виглядає «ідеально» здана домашка модуля 1: Arduino + `delay()`, нічого понад програму, але акуратно. Перевірено: збирається в PlatformIO для ESP32-S3-DevKitC-1.

| Файл | Що всередині |
|---|---|
| `src/two_pins.cpp` | базове завдання + всі «додатково», крім одного піна: потрійні спалахи, третій LED, зміна швидкості |
| `src/one_pin.cpp` | бонус: червоний і синій LED по черзі на **одному** GPIO |
| `platformio.ini` | два середовища: `pio run -e two_pins` / `pio run -e one_pin` |

## Схема (базовий варіант)

```
GPIO4 ── 150 Ом ──▶|── GND   червоний
GPIO5 ──  47 Ом ──▶|── GND   синій
GPIO6 ── 150 Ом ──▶|── GND   третій (додатково)
```

### Розрахунок резисторів — для **3,3 В**, а не 5 В
`R = (Vживл − Vf) / I`, цільовий струм ~10 мА:

| LED | Vf | R розрах. | Взято | Реальний I |
|---|---|---|---|---|
| червоний | 2,0 В | 130 Ом | 150 Ом | ≈ 8,7 мА |
| синій | 2,9 В | 40 Ом | 47 Ом | ≈ 8,5 мА |

Синій або білий LED від 3,3 В — «на межі»: на резистор лишаються десяті частки вольта, і струм сильно залежить від реальної Vf конкретного екземпляра. Якщо взяти «стандартні» 220 Ом, синій ледь світитиме. **Виміряй Vf свого LED мультиметром і перерахуй.**

## Чому код саме такий
- **Іменовані константи** (`PIN_RED`, `FLASH_ON_MS`) замість магічних чисел: щоб змінити пін чи темп, правиш один рядок.
- **Функція `flash(pin, count)`** замість копіпасти `digitalWrite/delay` по 12 разів.
- **Відомий стан на старті**: у `setup()` усе вимкнено.
- **Безпечні піни**: 4, 5, 6. Не 0/3/45/46 (strapping), не 19/20 (USB), не 26–37 (флеш/PSRAM).

## Бонус: один пін — два LED
Схема й пояснення — в шапці `src/one_pin.cpp`. Коротко:
- HIGH → струм іде з піна через червоний у GND;
- LOW → струм іде з 3V3 через синій у пін;
- `INPUT` (Hi-Z) → обидва гаснуть, **лише якщо** Vf₁ + Vf₂ > 3,3 В (червоний + синій ≈ 4,9 В ✔).

На 5-вольтовій платі або з двома LED з малою Vf у стані «вимкнено» обидва жевріли б. Межі свого трюку треба знати.

## Що здати разом із кодом
1. Схему (від руки / Fritzing / KiCad / ASCII) **з номіналами резисторів**.
2. Розрахунок резисторів.
3. Фото макета + коротке відео роботи.

## 🚀 На виріст (поза програмою модуля)
Цей код «глухий»: поки йде `delay()`, МК не може робити нічого іншого, наприклад читати кнопку. На наступних уроках той самий патерн перепишемо на `millis()`, і таблиця кроків стане основою кінцевого автомата.
