# Домашнє завдання 6.7 - рефакторинг

Вихідний код метеостанції для рефакторингу. Плата ESP32-S3-DevKitC-1, PlatformIO, `framework = espidf`, C17.

```bash
pio run -t upload -t monitor
```

Два "сенсори" (температура кожні ~100 мс, вологість кожні ~50 мс, симуляція через `esp_random()`) складають виміри у свої буфери в динамічній памʼяті. Задача звіту раз на 2 секунди друкує середнє, мінімум, максимум, кількість вимірів і free heap, потім очищає буфери. Сенсор вологості іноді "зависає" на 3 секунди.

Залиште плату працювати хоча б 10-15 хвилин і стежте за `free heap` у звіті.

Що треба зробити - у [`../Task.md`](../Task.md).

Порада: для перевірки на помилки додайте в `src/CMakeLists.txt`
`target_compile_options(${COMPONENT_LIB} PRIVATE -Wextra -Wshadow)`.
