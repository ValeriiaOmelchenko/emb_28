# Урок 1.6 — Практика: АЦП і фоторезистор

Скетчі для живої демонстрації на уроці 1.6. Фреймворк — **Arduino**, плата — **ESP32-S3-DevKitC-1**. Усі 6 кроків перевірено: збираються в PlatformIO.

## Схема

```
3V3 ──[ LDR ]──┬──[ 10 кОм ]── GND        подільник напруги
               │
             GPIO4   (ESP32-S3: ADC1_CH3)

GPIO7 ── 220 Ом ──▶|── GND                 світлодіод «нічника»
```

## Як запускати
Кожен крок — окреме середовище в `platformio.ini`:
```bash
pio run -e step3 -t upload
pio device monitor
```
У VS Code: панель PlatformIO → `env:stepN` → **Upload and Monitor**.

**Serial Plotter.** Кроки 2, 3, 5, 6 друкують рядки виду `raw:812 avg:805`. Їх малює Serial Plotter в Arduino IDE 2 (115200 бод). У VS Code можна взяти розширення **Teleplot**, але йому потрібен формат `>raw:812`, тож для нього треба додати `>` на початку кожного значення.

## ⚠️ Що навмисно НЕ входить у практику (це домашка)
Щоб код уроку не виконував ДЗ, у скетчах **немає**:
- `analogReadMillivolts()`;
- формули з `Uref = 3,1 В` (на уроці — ідеальна модель 3,3 В);
- порівняння двох напруг і розрахунку похибки, таблиці результатів;
- `analogReadResolution()` / `analogSetPinAttenuation()` (опційна частина ДЗ).

Крок 2 показує лише сам принцип «число → вольти». Чому ідеальна формула бреше і наскільки, студенти з'ясують у домашці.

## ⚠️ Піни АЦП: ESP32-S3 проти класичного ESP32
Багато матеріалів в інтернеті описують **класичний ESP32**: ADC1 = GPIO 32–39, ADC2 = GPIO 0, 2, 4, 12–15, 25–27. На **ESP32-S3** розкладка інша:

| | ESP32 (класичний) | **ESP32-S3** |
|---|---|---|
| ADC1 (працює завжди) | GPIO 32–39 | **GPIO 1–10** |
| ADC2 (конфлікт із Wi-Fi) | GPIO 0, 2, 4, 12–15, 25–27 | **GPIO 11–20** |

Схема уроку (**GPIO4**) на S3 — це **ADC1**, тобто правильний вибір. Порада «GPIO4 - це ADC2, беріть 32-39» стосується класичного ESP32, для S3 вона хибна: на S3 GPIO 32-39 взагалі не є АЦП-пінами. GPIO2 на S3 теж ADC1.

## Trust No Pin: що може піти не так на уроці
- **Число завжди ~4095:** на S3 АЦП із типовим послабленням (11 дБ) насичується приблизно на 3,1 В. Під ліхтариком «вершина» буде пласкою, і це нормально.
- **Число «плаває» без LDR:** пін висить у повітрі. Перевірити, чи вставлений резистор 10 кОм.
- **Число не змінюється:** середня точка подільника не на тому піні або LDR і резистор переплутані місцями (тоді логіка інвертується: світло → менше число).
